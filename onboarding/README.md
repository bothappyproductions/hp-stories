# Happy Productions client onboarding

Live at https://onboarding.happyproductions.video (Cloudflare Pages, build output directory: `onboarding`, no build command).

- `index.html` — the whole experience (Claire narration, steps, intake form → Airtable webhook)
- `vo/` — Claire voice lines, one MP3 per step; word timings live in the `CUES` object in index.html
- `media/` — photos, videos, client praise screenshots
- `_headers` — keeps the page out of search engines
